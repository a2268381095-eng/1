# 小恶魔助手 · 风格包

每个子目录是一套整体风格（服装 + 发型 + 袜子 + 姿势 + 道具 + 性格配成一套，不混搭）。
作品可以按写作背景切换风格。`default/` 是作者原稿，其他风格都以它为基准。

## 文件

| 文件 | 内容 |
| --- | --- |
| `sprite.txt` | 59×81 整帧像素表，一个字符一个像素，`.` 透明 |
| `style.json` | 名字、对应题材、额外颜色、眼睛/嘴/道具坐标、姿势与性格 |
| `draw.py`（可选） | 生成 `sprite.txt` 的脚本，改起来比直接改字符方便 |
| `preview_*.png`, `compare.png` | `tools/style_preview.py` 生成的检查图 |

```
python3 tools/style_preview.py styles/<id>
```

## style.json 字段

```json
{
  "id": "sailor",
  "name": "水手服·元气同桌",
  "genres": ["校园", "青春"],
  "colors": {"n": [40, 48, 92]},
  "eyes": {"left": [[31, 19], [31, 20]], "right": [[36, 17], [36, 18]]},
  "mouth": [35, 22],
  "prop_box": [8, 12, 18, 24],
  "pose": "一句话描述姿势",
  "personality": "一句话描述性格",
  "loose_ok": []
}
```

- `colors`：本风格新增的颜色，键是一个字符，不能和基础色重复。
  基础色已占用：`# 1 2 3 4 5 6 7 s S W g G E`。
- `eyes`：左右眼瞳孔（`E`）各两个像素的坐标，眨眼动画要用。
- `mouth`：张嘴时点亮的那个像素。
- `prop_box`：手上道具所在的矩形 `[x0, y0, x1, y1]`，道具会单独浮动或发光。
- `loose_ok`：确实不需要描边的像素（比如光点、半透明全息屏），写在这里检查就不报。

## 画风规矩（每套都要守）

1. **还是她**：粉色头发（`1`–`7` 粉紫色阶）、青色瞳孔 `E`、小恶魔尾巴（细尾 + 桃心尾尖）每套都在。
   脸直接从 `default/sprite.txt` 抄（第 16–24 行、第 26–40 列一带的五官），只改发型，不改五官和脸型。
2. **比例一致**：Q 版，头约占身高 1/3，整个人在 59×81 画布里，留 1–2 像素边。
3. **描边**：外轮廓 1 像素，用 `#`（58,26,44）。内部结构线用比填充色暗一级的颜色，不要满屏黑线。
4. **光源**：左上方来光。每种材质 3 级明暗（亮、中、暗），最多 4 级。不要从中心往外一圈圈变暗的“枕头阴影”。
5. **颜色**：一套风格新增颜色控制在 12 种以内，整套服装 2–3 个主色 + 1 个点缀色。
6. **干净**：不要孤立的单个杂点；斜线走 1:1、1:2 这类规整台阶；同一条边不要忽粗忽细。
7. **姿势要一眼认出**：只看黑色剪影也能分辨是哪套。招牌动作写在 `style.json` 的 `pose` 里。
8. **二次元**：可爱、俏皮，裙摆、发梢、缎带有动势，不要僵直站桩。

## 动作（每套至少 7 种）

每套风格都要有下面 7 种动作，**姿势按这套风格自己的特点来画**，不能只是原稿换衣服。
说话（嘴巴开合）和眨眼是叠加在任意动作上的，不算在 7 种里。

| 动作 id | 名字 | 用在什么时候 |
| --- | --- | --- |
| `idle` | 待机 | 平时待在角落，轻轻浮动或呼吸 |
| `wave` | 打招呼 | 打开软件、把她叫出来、第一次进某个板块 |
| `point` | 指路 | 引导流程时，指向下一步要点的地方 |
| `think` | 思考 | 等 AI 返回、全书查找、导入解析这类要等一会儿的事 |
| `cheer` | 欢呼 | 达成字数目标、写完一章、操作成功 |
| `shock` | 吓一跳 | 报错、删除前确认、全书替换命中很多处 |
| `doze` | 打瞌睡 | 很久没动静、深夜还开着 |

### 目录格式

```
styles/<id>/actions/<action>/
    draw.py      生成关键姿势的脚本（推荐）
    k1.txt ...   关键姿势，59×81 整帧像素表
    anim.json    帧序列
```

```json
{
  "action": "wave",
  "name": "打招呼",
  "loop": false,
  "colors": {},
  "keys": {
    "k1": {"eyes": {"left": [[31, 19], [31, 20]], "right": [[36, 17], [36, 18]]}, "mouth": [35, 22], "loose_ok": []},
    "k2": {"eyes": {...}, "mouth": [35, 22]}
  },
  "frames": [
    {"key": "k1", "ms": 120},
    {"key": "k2", "ms": 120, "dy": -1, "eyes": "closed", "mouth": "small"}
  ]
}
```

- `colors`：这个动作额外用到的颜色（汗滴、Zzz、光点），键不能和风格里已有的重复。
- `frames` 里每帧可设 `dx` / `dy`（整体平移）、`eyes`（`open` / `half` / `closed`）、`mouth`（`small` / `open`）。
  特殊表情（笑眼、哭脸、吓得睁大眼）直接画进关键姿势里。
- 一个动作一般 2–4 个关键姿势、6–12 帧；循环动作首尾要接得上，播一遍的动作最后一帧回到接近待机的姿势。

```
python3 tools/action_preview.py styles/<id>/actions/<action>
```
生成 `anim.gif`（看效果）、`strip.png`（逐帧检查）、`frames.png`（拼精灵表用）。
