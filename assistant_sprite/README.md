# 写作小助手像素小人

`sprite.txt` 是原画初稿的 1:1 像素表（55×76，14 色，从原图逐格取色，已校验与原图一致）。
一个字符就是一个像素，`.` 为透明，颜色对应关系见 `build.py` 里的 `PALETTE`。

```
python3 build.py
```

生成到 `out/`：

| 文件 | 内容 |
| --- | --- |
| `replica.png` / `replica_8x.png` | 初稿原样复刻（1 倍 / 8 倍） |
| `still.png` / `still_8x.png` | 新造型静帧：裙下两条粉色长条合成一条小恶魔尾巴 |
| `sheet.png` | 精灵表，每格 59×81，一行一个动画 |
| `sheet.json` | 每个动画所在行、帧数、每帧毫秒数 |
| `gif/*.gif` | 各动画单独的透明 GIF（6 倍） |
| `preview.gif` | 所有动画串在一起的预览 |

`preview.html` 是交互预览页：模拟写作软件界面，切换动作、调大小和速度、逐帧查看。和 `out/` 放在同一目录下用浏览器打开即可。

## 动画

| 名字 | 说明 |
| --- | --- |
| `idle` 待机 | 整体上下浮 1 像素，发尾在上浮时滞后拉长，手上方的光球慢半拍、浮得更高，尾巴慢慢左右摆 |
| `blink` 眨眼 | 待机 + 半闭 → 闭眼 → 半闭 |
| `talk` 说话 | 待机 + 嘴巴开合 |
| `idea` 灵感 | 光球亮起冒光点，人跟着一跳，眼睛笑成 ^ ^，尾巴快速甩 |

尾巴不在 `sprite.txt` 里，由 `build.py` 的 `devil_tail()` 按曲线画出来，改弯度或摆幅调那里的控制点。

在软件里建议循环播放 `idle`，隔几秒随机插一次 `blink`；出提示时播 `talk`，给出建议时播 `idea`。
放大显示时用最近邻缩放（CSS 写 `image-rendering: pixelated`），否则会糊。
